# 🌸 Floora Shop

**Tagline:** Where Every Bloom Tells a Story.

## About Project
Floora is a modern flower e-commerce website where customers can explore and purchase beautiful flowers, bouquets, and flower pots.

## Technologies Used
- HTML, CSS, JavaScript
- React.js + Vite
- React Router
- Firebase (Planned Integration)
- GitHub & Vercel

## Main Features
- Attractive Home Page
- Indian Flowers
- International Flowers
- Bouquets
- Flower Pots
- Product Search & Filters
- User Profile & My Dashboard
- Shopping Cart & Orders
- Admin Panel
- Responsive Design

## Project Type
Flower E-Commerce Website

## Project Name
Floora Shop 🌷
